# Manas Mallik — Mechanical Design Engineer Portfolio

Static, GitHub Pages-ready portfolio built without a framework or external runtime dependency.

## Files
- `index.html` — semantic portfolio structure
- `styles.css` — responsive visual system and animations
- `script.js` — scroll reveal, active navigation, project case modals
- `assets/favicon.svg` — lightweight favicon
- `resume.pdf` — CV download
- `.nojekyll` — GitHub Pages compatibility
- `404.html` — fallback page
- `robots.txt` — crawler guidance

## GitHub Pages
1. Put these files in the repository root.
2. Commit to `main`.
3. GitHub → Settings → Pages.
4. Select **Deploy from a branch**, branch `main`, folder `/root`.
5. Save and open the generated Pages URL.

No build command is required.
